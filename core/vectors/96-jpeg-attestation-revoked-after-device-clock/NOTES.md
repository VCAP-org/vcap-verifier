# 96-jpeg-attestation-revoked-after-device-clock

Vector 45 without the timestamp token. The revocation date is thirty days after `time.device_clock` — and the device clock is set by whoever holds the device key, which after a leaked keybox is exactly the person the revocation is about. A thief who signs today with the clock set to last month would read *revoked after the capture* and keep the level. So a device clock never places a capture before a revocation: **red** (§6.2, §7).

Generated by `tools/src/generate.ts` with the test key in `tools/src/testkey.ts`.
