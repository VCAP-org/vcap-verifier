# 32-jcs-core-canonicalization

A proof with keys in writer order, a negative integer and a zero. The core is the eight §6.1 keys only (sig and registry are excluded), serialized per RFC 8785: keys sorted by UTF-16 code units at every level, no whitespace, integers as plain decimals.

Generated by `tools/src/generate.ts` with the test key in `tools/src/testkey.ts`.
