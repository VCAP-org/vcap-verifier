# 60-jpeg-timestamp-other-imprint

A genuine token from the trusted TSA, over **somebody else's** core hash. Every signature in it verifies; it simply timestamps a different proof.

This is the case that makes the imprint check the first one worth doing, and the one a naive implementation misses by validating the CMS and reading `genTime` without asking what was stamped. A verifier that did would date this capture by a stamp taken over an unrelated file. The instant falls back to `device_clock` and both labels of §8 are shown.

Generated by `tools/src/generate.ts` with the test key in `tools/src/testkey.ts`.
