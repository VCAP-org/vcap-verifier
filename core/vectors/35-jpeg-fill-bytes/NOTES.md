# 35-jpeg-fill-bytes

A 0xFF fill byte precedes a marker in the header. §4.1 keeps fill bytes and length-less markers where they are: the canonical bytes are the file minus the trailer, and media.hash matches. A walker that treats the fill byte as a marker misparses the file and fails this vector.
