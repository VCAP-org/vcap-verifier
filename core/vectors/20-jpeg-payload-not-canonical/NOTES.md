# 20-jpeg-payload-not-canonical

The trailer payload is pretty-printed, keys in writer order, not JCS. The verifier recomputes JCS(core) from the parsed JSON (§4.2): the bytes in the trailer are not authoritative. Writers MUST still emit canonical JSON; this vector tests the reader.
