# 103-jpeg-timestamp-after-anchor-block

A valid token and a verified anchor over the same core, and the token's `genTime` is **after** the block that already anchors it. A token is validated at its own `genTime`, which whoever holds the TSA key chooses; the block time is chosen by nobody. When both are present the token must predate the block, and its signer certificate must still have been valid at the block (§6.2). This one fails the first: both labels of §8 for the token, and the block dates the capture.
