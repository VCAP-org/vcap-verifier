# 46-jpeg-missing-media-dimensions

Vector 01 with media.w and media.h removed after signing. §8 requires them: every writer holds the dimensions at capture, and a reader that cannot say how large the frame is cannot place a watermark payload or a segment in it. Missing is malformed — no proof found, not tampered — the same shape as an absent capture_id (vector 21), and like that vector the signature is never examined: the shape check of §8 fires first, so a verifier that reported *tampered* here would be reporting a check it had not run.
