# 62-jpeg-timestamp-no-eku

A signer certificate issued by the **trusted** root, with the right imprint and a valid signature, and no `timeStamping` extended key usage.

The check that catches it is the one easiest to leave out, because everything else about the token is impeccable. A TSA root signs more than its own stamping key — TLS certificates, other services — and without the EKU any of those could stamp. RFC 3161 requires the extension and requires it critical; this is the vector that says a verifier must read it.

Generated by `tools/src/generate.ts` with the test key in `tools/src/testkey.ts`.
