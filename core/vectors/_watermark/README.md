# Watermark layout vectors

`layouts.json` pins the two payload layouts of
`spec/watermark-layouts-1.0.md`: for each, worked cases mapping an input — a
capture id for `photo-bch-v3`, a `mark_id` for `video-rep-v1` — to the 256-bit
message it becomes, hex, MSB-first within each byte.

Not run by the vector harness, and deliberately not numbered: these are not
verdicts on a sealed file, they are the encoder's arithmetic. A port checks
itself against them before it ever meets a detector, which is the cheap place
to find a bit-order mistake — the expensive place is a payload that does not
decode out of a real recording, where a hundred things could be wrong.

Generated by `vcap-ml` (`python -m vcap_ml vectors`) and copied here, because
the layouts are public and the model that carries them is not.
