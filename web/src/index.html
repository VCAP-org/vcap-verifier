The original

A copy that came back re-compressed, cropped or through a social network has usually lost its proof. Next to the original, this page can show what it lost and what it kept.

A sidecar file

When the proof travels beside the file rather than inside it (<filename>.vcap). It is read here, not looked for anywhere.

What this page trusts

Every check below can be switched off, and switching one off never turns a verdict into an error — it turns a line of evidence into not evaluated, which is a weaker answer and an honest one.

Transparency logs

A sealed file can prove its signing key was published in a transparency log before the capture. Checking that needs the log's public key, so this page ships with a set — visible here, switchable, replaceable with your own. The same set is published beside this page as logs.json: fetch it, recompute each log_id from its key, and decide for yourself.

    A proof naming a log you do not follow reads log not trusted. The rest of the verdict is unchanged.

    Timestamping authorities

    A sealed file can carry an RFC 3161 token binding its proof to an instant. Checking it needs that authority's root certificate, so this page ships with a set, published beside it as tsa.json. Unlike the logs above these authorities are run by other people — which is what makes a token worth having, and why what it proves has to be stated narrowly.

      With all of them off, a timestamp reads trusted time not evaluated and certificates are validated at the instant the device claims instead.

      Your own TSA trust document

      What this page can and cannot tell you is written in the vcap specification and its threat model. The proof level (secure hardware) needs the attestation chain and is not evaluated here yet. A position is never “guaranteed”: the page names the level it reaches — declared by the device, or corroborated by a registry it trusts.

      The log it ships with is run by the same people who publish this page: it proves a key was in our log, never that we are honest. The timestamping authorities are run by other people: a token proves a hash existed before an instant, never who made the file.
