      Public chains read for anchors

      For a proof with an anchor, this page asks the chain's public endpoint in chains.json which root the contract stored. The request carries the anchor id only — never the file or the proof. Off, or offline, an anchor reads anchoring not verified.

        What this page can and cannot tell you is written in the vcap specification and its threat model. The proof level (secure hardware) is read from the Android attestation chain in the file, checked against Google's pinned roots, or from the registry leaf for iOS. A position is never “guaranteed”: the page names the level it reaches — declared by the device, or corroborated by a registry it trusts.

        The log it ships with is run by the same people who publish this page: it proves a key was in our log, never that we are honest. The timestamping authorities are run by other people: a token proves a hash existed before an instant, never who made the file.
